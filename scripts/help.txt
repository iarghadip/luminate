Usage: build.sh [OPTIONS]

Options:
  -fc, --filecompile   Preprocess and minify files in the web directory only.
  -fs, --filesystem    Build and upload the filesystem image (SPIFFS/LittleFS).
  -fw, --firmware      Build and upload the firmware (C++ program).
  -a,  --all           Run all steps: preprocess/minify web files, build/upload filesystem, and build/upload firmware.
  -h,  --help          Display this help message and exit.

Description:
  This script automates building and uploading firmware and/or filesystem images
  for the ESP32 using PlatformIO. Use the flags to specify which parts to build
  and upload. It also compiles HTML/JS files in the web directory by minifying
  and replacing template variables from platformio.ini.

Examples:
  ./build.sh -a
      Run all steps: preprocess/minify web files, build/upload filesystem, and build/upload firmware.

  ./build.sh -fw
      Build and upload firmware only.

  ./build.sh -fs
      Build and upload filesystem only.

  ./build.sh -fw -fs
      Build and upload both firmware and filesystem.

  ./build.sh -fc
      Only compile web files (HTML/JS): minify and inject build-time variables.
